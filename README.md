# Booking-API
Это API для тестового задания

Проект запускается через uvicorn командой uvicorn app.main:app 
Принял решение сделать проект через базу данных SQLite,
в качестве ORM использовать SQlAlchemy,
так как так написано в ТЗ и это дает дополнительные баллы

Структуру проекта реализовал продумано, с возможностью легкого расширения в дальнейшем.
Был реализован асинхронный менеджер жизненного цикла в main, который создает таблицы и индексы до запуска приложения.
В базе данных есть индекс, который не дает создать две записи на одинаковое время
Также создал удобный генератор сессий (get_session).
Все модели и схемы данных выведены в отдельные директории для удобной работы с ними
Также сделал небольшое покрытие тестами
